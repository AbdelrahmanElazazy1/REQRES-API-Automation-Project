# REQRES API Automation Project

This project automates API tests for the REQRES API using the following technologies:

* **Rest Assured:** For making HTTP requests and validating responses.
* **TestNG:** For test execution and reporting.
* **Page Object Model (POM):** For maintaining reusable API request specifications.
* **Allure Reporting:** For generating comprehensive and visually appealing test reports.
* **Gson:** For JSON serialization/deserialization.

## Features

* **Automated API Tests:**
    * Covers various API endpoints (GET, POST, PATCH, DELETE).
    * Includes comprehensive test cases for user management, resource creation, and other API functionalities.
* **Page Object Model (POM):**
    * Encapsulates API interactions within reusable classes for better maintainability and code reusability.
* **Allure Reporting:**
    * Generates detailed and visually appealing test reports with comprehensive information about test execution, including test steps, logs, and attachments.

## Prerequisites

* Java Development Kit (JDK) 11 or later
* Maven
* IntelliJ IDEA or any other suitable IDE
